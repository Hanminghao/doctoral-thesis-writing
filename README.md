# Doctoral Thesis Writing Skill

A Codex skill for planning, drafting, revising, and auditing Chinese doctoral theses built from multiple research works.

## Modes

- `outline`: global dissertation structure and claims–evidence matrix
- `introduction`: Chapter 1
- `foundation`: research foundations and shared notation
- `work`: one paper-derived research chapter
- `system`: system or application validation chapter
- `conclusion`: summary and outlook
- `audit`: whole-thesis consistency, evidence, citation, and similarity checks

The skill uses reference dissertations only for chapter functions and argument structure. It requires original prose based on the user's own papers, experiments, and verified sources.

## Install

Copy this directory into `$CODEX_HOME/skills/doctoral-thesis-writing` or `~/.codex/skills/doctoral-thesis-writing`.
